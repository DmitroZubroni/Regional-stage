# Чек-лист перед показом

Без него макет, вёрстка и презентация не уходят клиенту. Пункт не выполнен —
исправляем или письменно фиксируем исключение.

## Функциональность
- [ ] Все роли, у каждой свои экраны, главные задачи в 1–2 касания (Ф2, Ф4)
- [ ] Сценарии с ошибками и возвратом; крайние случаи пройдены (Ф5)
- [ ] Расширенный функционал предложен по MoSCoW (Ф9)
- [ ] Метрики и события аналитики определены (Ф10)

## Композиция и система
- [ ] Главное понятно за 3 секунды, squint test пройден (К1, К10)
- [ ] Одна главная кнопка на экран (К1)
- [ ] Отступы и шрифты только из шкал (С1, Т2)
- [ ] Цвета только из токенов (Ц7)
- [ ] Одинаковое выглядит, называется и работает одинаково (К8)

## Текст
- [ ] Основной текст ≥ 16 px, межстрочный ~1.5, строка ≤ 75 символов (Т3, Т5, Т6)
- [ ] Русская типографика, тексты словами пользователя, нет «Lorem ipsum» (Т10, Ф7)
- [ ] Тексты из CMS и базы проходят через `typograph()`, длинные слова переносятся (Т10)

## Цвет и доступность
- [ ] Контраст проверен инструментом или `tools/contrast.py` (Ц4, Н2)
- [ ] Текст акцентным цветом — токеном `accent-text`, а не заливкой `accent` (Ц8)
- [ ] Смысл не только цветом (Ц6)
- [ ] Области нажатия ≥ 44 × 44 px; плотный режим 24 px — только для внутренних систем с мышью (Д1)
- [ ] Пройдено клавиатурой, фокус виден (Д2)
- [ ] Lighthouse Accessibility ≥ 90

## Удобство
- [ ] У каждого экрана есть пустое состояние, загрузка, ошибка, успех (У1)
- [ ] Из каждого сценария есть выход, данные не теряются (У3)
- [ ] Формы по правилу У9

## Экраны с данными (если есть)
- [ ] Только нужные столбцы, числа вправо, шапка закреплена (Л1, Л2)
- [ ] Проверено на 500 строках и самых длинных значениях; телефон — карточки (Л3)
- [ ] Фильтры видны и в адресе; возврат из карточки сохраняет список (Л4, Л5)
- [ ] Массовое действие: точное число, отмена или честное подтверждение (Л6, Л7)
- [ ] Графики: столбцы от нуля, одна ось, легенда, таблица данных (Л9)
- [ ] Числа дашборда сходятся со списками, на которые ведут (Л10)

## Тексты и живые люди
- [ ] Кнопки глаголом, ошибки говорят, что делать, подпись не в `placeholder` (Я1–Я3)
- [ ] Пустые состояния и подтверждения написаны, а не «Нет данных» и «Вы уверены?» (Я4, Я5)
- [ ] Одно понятие — одно слово, глоссарий в `docs/` (Я6)
- [ ] Главный сценарий проверен на 3 людях вне проекта; блокеры исправлены (Ю1–Ю3)

## Адаптивность
- [ ] 320, 375, 768, 1024, 1280, 1440 px — без горизонтальной прокрутки (С5)
- [ ] Автоматический аудит `tools/audit` пройден без ошибок (Н5)
- [ ] Каждый выпадающий список открыт на 375 и 1280 px и у нижнего края: ширина поля, перенос, в пределах экрана, выбор мышью, клавиатурой и касанием (Н6)
- [ ] Каждое состояние открыто через демо-переключатель и проверено (Н4)
- [ ] Частые действия на телефоне внизу (С6)

## Презентация
- [ ] Каждый слайд — вывод в заголовке и понятен за 3 секунды (П1, П2)
- [ ] Для отправки по почте сделана версия-слайдомент (П4)
- [ ] Проверено на проекторе или с расстояния (П5)
- [ ] Есть финальный слайд со следующим шагом (П12)

## Оформление (если подключён модуль)
- [ ] Мотив один и проходит через весь продукт (О7)
- [ ] Иконки одного набора; украшения скрыты от экранных дикторов и уважают reduced motion (О7, Д8)

## Финал
- [ ] Посмотрел свежим взглядом, не сразу после работы
- [ ] Показал человеку не из проекта
